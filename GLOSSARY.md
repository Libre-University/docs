# Sözlük

Bu sözlük LibreUniversity dokümanlarında geçen kısaltma ve terimleri açıklar. Amaç, üniversite süreçlerine veya yazılım alanına yeni katkıcıların dokümanları ek araştırma yapmadan okuyabilmesidir.

## Üniversite ve Mevzuat Terimleri

| Terim | Açıklama |
| --- | --- |

## Yazılım ve Mimari Terimleri

| Terim | Açıklama |
| --- | --- |
| ADR | Architecture Decision Record; gerekçeli mimari karar kaydı. Bkz. [docs/adr/](docs/adr/). |
| Adapter | Dış sistemi çekirdekten izole eden, değiştirilebilir entegrasyon katmanı. Bkz. [ADR-0007](docs/adr/0007-isolate-external-systems-with-adapters.md). |
| AsyncAPI | Event ve mesaj akışlarını tanımlayan sözleşme standardı. |
| Audit log | Kim, neyi, ne zaman yaptı bilgisini değiştirilemez şekilde tutan denetim izi. |
| BI | Business Intelligence; raporlama ve analitik katmanı. |
| CMS | Content Management System; web içerik yönetim sistemi. |
| Contract-first | Kod yazılmadan önce API ve event sözleşmelerinin yazılması yaklaşımı. |
| DCO | Developer Certificate of Origin; katkıcının commit'te `Signed-off-by` ile verdiği kaynak beyanı. |
| depguard | golangci-lint kuralı; hangi paketin hangi paketi içe aktarabileceğini denetler, modül sınırlarını korur. |
| GIS | Coğrafi Bilgi Sistemi. |
| ILS | Integrated Library System; kütüphane otomasyonu. |
| Jibri | Jitsi toplantılarını kaydeden açık kaynak bileşen. |
| Jitsi | Açık kaynak video konferans yazılımı. |
| JVB | Jitsi Videobridge; video akışlarını dağıtan sunucu bileşeni (SFU). |
| JSON Schema | JSON verisinin yapısını doğrulayan şema standardı. |
| JWT | JSON Web Token; imzalı kimlik ve yetki taşıyan token formatı. |
| Keycloak | Açık kaynak kimlik ve erişim yönetimi sunucusu. |
| MFA | Multi-Factor Authentication; çok faktörlü kimlik doğrulama. |
| MinIO | S3 uyumlu açık kaynak nesne depolama. |
| MVP | Minimum Viable Product; ilk çalışan çekirdek sürüm. Bkz. [MVP_SCOPE.md](MVP_SCOPE.md). |
| Modüler monolith | Tek uygulama olarak dağıtılan, iç sınırları modül bazında korunan mimari. Bkz. [ADR-0004](docs/adr/0004-start-with-modular-monolith-for-mvp.md). |
| oapi-codegen / sqlc | OpenAPI ve SQL dosyalarından tip güvenli Go kodu üreten araçlar. Bkz. [ADR-0011](docs/adr/0011-use-go-for-backend.md). |
| OIDC | OpenID Connect; OAuth 2.0 üzerine kurulu kimlik doğrulama protokolü. |
| OpenAPI | REST API'leri tanımlayan sözleşme standardı. |
| Port / Adapter | Port: çekirdeğin beklediği Go arayüzü; adapter: bu arayüzü belirli bir dış sistem için uygulayan paket. |
| PWA | Progressive Web App; mobil uygulama gibi kurulabilen web uygulaması. |
| River | PostgreSQL üzerinde çalışan Go arka plan iş kuyruğu; Redis gerektirmez. |
| RPO / RTO | Recovery Point / Time Objective; felaket durumunda kabul edilen veri kaybı süresi ve geri dönüş süresi. |
| SAML | Kurumsal SSO için XML tabanlı kimlik protokolü. |
| SBOM | Software Bill of Materials; bağımlılık envanteri. |
| SEB | Safe Exam Browser; online sınav için kilitli tarayıcı. |
| SFU | Selective Forwarding Unit; video akışlarını yönlendiren sunucu mimarisi. |
| SIEM | Security Information and Event Management; güvenlik olay yönetimi. |
| SSO | Single Sign-On; tek oturum açma. |
| VOD | Video on Demand; kayıtlı ders videosu. |
| WCAG | Web Content Accessibility Guidelines; web erişilebilirlik standardı. |
